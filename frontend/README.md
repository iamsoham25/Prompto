# Prompto

Prompto is an AI-powered prompt learning and evaluation platform designed to help users create, analyze, improve, and evaluate prompts.

The platform provides prompt evaluation across multiple dimensions, tracks user progress, maintains prompt history, and helps users improve their prompt engineering skills.

---

## Features

### Prompt Evaluation

Prompts are evaluated across multiple dimensions:

- Clarity
- Specificity
- Context
- Constraints
- Role Definition
- Output Format
- Examples

Each prompt receives an overall score out of **100**, along with individual evaluation scores.

---

### Prompt History

The application allows users to:

- Save evaluated prompts
- View previously analyzed prompts
- View the overall evaluation score
- View individual evaluation breakdowns
- Delete prompt history records
- Maintain prompt history separately for each user

The Prompt History system stores one evaluation record for each submitted prompt.

---

### Additional Features

The platform also includes:

- Prompt Learning
- Prompt Playground
- Prompt Comparator
- Prompt Templates
- Prompt Improver
- Prompt Challenges
- Prompt Evaluator
- User Analytics
- User Dashboard
